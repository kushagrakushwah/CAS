# test_video/

This folder contains test videos for video detection and hazard alerts.

| File | Scenario | Duration | Resolution |
|---|---|---|---|
| `pedestrians_street.mp4` | Street view with multiple people walking | ~5.0s | 960x540 @ 30 FPS |
| `pedestrians_crossing.mp4` | Street crossing with pedestrians | ~5.0s | 960x540 @ 30 FPS |

You can test them directly from the Streamlit **Video Upload** page by clicking the sample buttons or uploading from this folder.
